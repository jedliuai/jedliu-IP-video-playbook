# 个人 IP 视频制作规则

一套面向"真实工作场景 + AI"类个人 IP 的视频创作规则：从选题、脚本、拍摄、剪辑包装、声音，到分平台版本与合规、发布运营，按制作阶段拆成模块，随实际制作持续迭代。

## 从哪里开始

从 [`v3-模块化/`](v3-模块化/README.md) 开始 —— 模块索引、已定事项、待定事项都在里面。这是唯一有效的版本，旧的单文件版本已删除（可在 git 历史中找回）。

## v3 模块

| 模块 | 内容 |
|---|---|
| M1 选题与定位 | 定位、选题、真实性底线 |
| M2 脚本 | 钩子、结构、章节、口播、结尾 |
| M3 拍摄与录屏 | 机位、录屏、脱敏素材 |
| M4 剪辑与包装 | 小窗、章节卡、字幕、展映 |
| M5 声音 | 人声、响度、音乐音效 |
| M6 平台版本与合规 | A/B 版差异、结尾、AI 标注 |
| M7 标题发布与运营 | 标题公式、复盘、对标机制 |
| M8 检查清单 | 每期出片前勾选 |
| X 对标取舍 | 对标账号逐条采纳／改造／不采及证据可信度 |

## 约定

- 通用型修改经确认后才写入规则；规则只写在它所在的那一个模块里，其余用链接引用。
- 规则里没有的平台细则不写死；平台审核条款会变，以各平台当时的官方规范为准。
- 本仓库只放规则文本，不含视频、录屏、客户或订单数据。
