# M6 平台版本与合规

## 只出两版（硬规则）
1. 每期只出 **A 版**（B站、YouTube、视频号）和 **B 版**（抖音、小红书）。不出第三版。
2. 抖音和小红书共用同一个 B 版文件，按更严的标准做。
3. 某平台对 B 版结尾出现限流或违规提醒，只替换结尾最后一句，不算新版本。
4. 以后有变化，由你提出后再改本节。
5. 脚本、录制按"正常内容"做，不为审核提前自我阉割；先做 A 版，再从 A 派生 B 版（删减＋替换，不重做）。

| | A 版 | B 版 |
|---|---|---|
| 演示／技术细节 | 完整保留 | 敏感片段删除，或用示意／其他画面替换 |
| 商业信息 | 可适度保留（服务提示、简介引导） | 无广告植入、站外引流、营销话术、服务提示；口播不念网址；无联系方式（画面里自然出现的公开 GitHub 仓库地址不算，见 [M3](M3-拍摄与录屏.md)） |
| 敏感选题 | 可正常讲 | 改角度或整期不发 |

## 结尾（15–20 秒）
- 结构：复盘一句（≤25 字）→ 价值句（这一期自己的具体结论，不是口号，不设固定签名句）→ 至多一个有理由的动作 → 说完即停（≤0.5 秒）。
- 不加片尾卡、黑屏、告别画面（镜头停在最后一句字幕上）；不喊点赞／收藏／三连、不说"感谢观看"、不做情绪升华；语速保持正文水平，BGM 不在价值句处拉高；不用 Star／福利／奖品／官方活动式结尾。
- 告别语：B 版（短版）不加；B站／YouTube 长版可选加一句轻告别。
- **动作**（模板全文见 `分析/05`）：
  - A 版：评论区拿模板／预告下期／交作业／坦诚边界／极简无动作。说了"评论区告诉我"就要回复并给获取路径（如 jedliuai.com）。
  - B 版：评论区拿资料（`评论区告诉我你想要哪个`）、预告下期＋关注理由（`对我的作品感兴趣，关注我就行`，可用画面文字叠在最后一句上）、坦诚边界（去掉链接）、极简无动作。不用交作业、私信引导、点赞收藏引导。
  - 评论区拿资料：资料必须真有（脱敏模板、提示词、流程文件）；说了就要回复；不在视频里引导去站外。

## 违禁词（B 版）
- "绿盾"是抖音的违禁词：不说、不写、不出现在画面、标题、简介、标签、评论里，统一说"加密软件"；A 版录制时口播也直接这样说，B 版就不用重录。
- 不要为了避词删掉解密相关内容：保留流程，换词，画面里的相关文字做遮挡。
- "天锐／Tipray"是否要避开：未确认，暂按回避处理。新发现的违禁词，经你确认后追加到本节。

## 其他
- **服务提示**：固定文案、右上角、每片 ≤3 次，不写"官方"；只用于 A 版。有真实商业合作，按平台要求标注。
- **AI 内容**：语音转换、AI 生成素材（含章节卡插画）按平台要求声明／标注，并如实回答平台的 AI 内容申报。
- **敏感选题**：先判断值不值得发，再决定改角度、只发 A 版，还是放弃。
