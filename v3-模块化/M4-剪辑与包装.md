# M4 剪辑与包装

## 1. 画面形态（交替切换）
| 形态 | 用法 |
|---|---|
| 全屏真人中景 | 开场、总结、观点、转折句 |
| 录屏 + 圆形真人小窗 | 所有软件操作 |
| 纯录屏／素材 | 成果展映、对比图、成品 |
| 章节卡 | 每章开头，1.5–2 秒 |
| 流程图／提示词卡 | 圆角白卡，红框或红下划线高亮重点 |

- 单个镜头约 **2.5–5 秒**切换一次（录屏操作段可更长）；整体**紧而不赶**。

## 2. 圆形小窗
- 直径约占画面宽 18–25%，细白描边，固定在一角（左下／右下，必要时换右上）。
- **不遮挡操作区**；换角位要有理由。

## 3. 章节卡（学骨架，不学外观）
> 更正：木子的章节卡**不是统一模板**，每条视频按主题单独设计外观（底色、配色、入场动画都换），10 条里一致的只有下面的骨架。依据 `分析/04-章节卡专项分析.md`。

- **骨架（必有）**：大号编号 ＋ 2–7 字短标题（可带一句小号副标题）＋ 一张与本章主题对应的 3D 插画 ＋ 页码 `N / M` ＋ 停留约 **1–1.8 秒**，**此时口播暂停**。
- 可选：分段进度条；每章换一个强调色；入场动画（翻页、数字冲屏、卷页等）。
- 你每两周一期、不必像他每期重做：**固定一套自己的品牌外观**（配色、字体取自头像／Logo／既有 Remotion 风格），**每章只换标题和插画**。不照搬他的深绿＋奶白网格纸。
- 插画可用 AI 生成（付费额度按既定规则谨慎用），用 Remotion 做固定模板。

## 4. 字幕
- 位置：底部居中。目标 **8–14 字／行**，硬上限 18 字。
- **录屏／素材镜头加半透明深色圆角底板**；真人干净背景可不加，改白字黑描边。
- 断行规则沿用既有：按停顿与语义断，不拆词，不拆"的／在／把／就"之后；逐行校对识别错字。

## 5. 花字与标签
- 关键词花字：0.2 秒缩放弹入，停留 1–2 秒，放人物侧面。**克制**，一屏一个。
- 左上角药丸标签：写当前场景／设备（"电脑端""手机端""Excel""终端"）；多窗口切换必加。
- 高亮：红／橙圆角框；关键操作 130–180% 平滑推镜；鼠标放大＋点击波纹。

## 6. 成果展映
- 每期留 **10–20 秒**，口播静音，只放真实运行画面和原声，用来兑现开头承诺。

## 7. 片尾
- 结尾**不做片尾卡、黑屏、告别画面**：真人镜头停在最后一句字幕上，说完最多再停 0.3–0.5 秒（见 [M6 结尾](M6-平台版本与合规.md)）。
- 与卡通形象的关系：之前计划吉祥物出现在片头、转场、片尾；片尾是否保留，见 README"仍待定"。

## 8. 转场、B-roll、音效、音乐
- 必须有；转场固定一套，复用，不每期重做。
- 卡通形象用于片头、转场、片尾；**不另加没商量过的"签名"元素**。
- 音效选柔和的（轻 pop／whoosh），不用连续的"机枪"声。
