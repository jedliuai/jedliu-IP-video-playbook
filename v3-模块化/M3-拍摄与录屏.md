- 横屏 16:9；人像和屏幕分轨录制（OBS：`*_cam` 与 `*_screen`）。录前备好虚构／脱敏演示文件。
- **要处理**：客户名、邮箱、订单号、价格、密钥、含隐私的路径、审批人姓名。
- **不用打码**（2026-11-10 你确认）：公开的 GitHub 仓库地址（地址栏、粘贴进对话框的链接、来源面板里的链接）；所演示的数据网站页面和它的登录二维码。
- 真人：正面中景，头顶留白约 10%，柔光。不抄木子的识别点（黑 T、黑框眼镜、领夹麦外露、橙发少女油画），用自己的"打工人桌面＋真实业务界面＋头像／Logo"。
