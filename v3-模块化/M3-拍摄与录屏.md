# M3 拍摄与录屏

## 总体
- 横屏 16:9；人像和屏幕**分轨录制**（OBS：`*_cam` 与 `*_screen`），后期由 Claude 合成。
- 录前先备好**虚构／脱敏演示文件**，不要边录边找。

## 真人
- 机位：正面中景（胸部以上），头顶留白约 10%，居中或略偏左。
- 光：正面偏侧约 45° 柔光，面部通透、无油光、眼镜无反光。
- 背景与服装：**不抄木子的识别点**（黑 T + 黑框眼镜 + 领夹麦外露 + 橙发少女油画）。用自己的"打工人桌面 + 真实业务界面 + 头像／Logo"建立辨识度。

## 录屏
- 屏幕按原生分辨率录（当前 2560×1440），光标保留，便于后期放大鼠标。
- 操作时放慢关键一步，留出推镜与高亮的余量。
- 多窗口／多设备切换时，每次切换停一拍，后期要打左上角场景标签（见 [M4](M4-剪辑与包装.md)）。
- 圆形小窗位置在剪辑时定：固定一角，**不遮挡操作区**。

## 口播录制
- 稿子按 [M2](M2-脚本.md) 写（240–280 字／分钟），录完再剪气口。
- 保留自己说话的人味，不要读稿腔。
- 出错或关键步骤如果真发生了，就如实录下，不补演。
