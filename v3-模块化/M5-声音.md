# M5 声音

- **人声**：高通 → EQ → 压缩 → 一次静态增益；**不用动态响度（loudnorm）**，否则忽大忽小和毛刺。**混音里不对人声限幅**（音乐音效撞击时人声被压是毛刺的来源）；人声单独处理时，末尾只允许一道慢释放限幅削尖峰，削幅 ≤ 约 4 dB，超了就降人声目标响度，不硬压。防风海绵麦偏闷：EQ 削 130–520 Hz、轻提 1.5–2.8 kHz，不加混响；录音停顿处是数字静音，不需降噪。
- **整体匀声（2026-11-12）**：录着录着麦克风位置、坐姿会变，不同时段电平能差 5–10 dB。剪辑时按每一段的说话电平（50 ms 窗 RMS 的 75 分位）对齐到全片中位数，增益限制 −4～+10 dB，相邻几段取中位数平滑，≥1.2 dB 才调；出片后分段（2 秒窗）测一遍，说话段应落在约 3 dB 范围内，有突然变小的段落要回头查。
- **语速**：按段整条拉伸（约 1.10–1.34×，由每段实测字数／秒定；你嫌慢时开头按 ×1.2–1.25），用 rubberband 保共振峰、每个 take 的整段只拉一次再切片，人像小窗按同倍率取帧保口型；不用全局固定倍速，不对小片段单独拉伸；去开头口癖（然后／那么／呃／额）和重复句，通读保留的逐字稿再定稿。
- **响度**：整片约 −14 LUFS，真峰值 ≤ −2 dBFS；展映段人声静音，原声与口播同级或略高。**人声单独的标准 −14.5 LUFS（双声道，双单声道复制），真峰值 ≤ −2 dBTP（脚本留 0.3 dB 余量）**；先把人声定到这个值再加 BGM，不再用耳朵凭感觉。
- **音乐音效**：BGM 不盖人声，高通 160 Hz、低通 9 kHz，ducking 释放要慢；音乐、音效各自限幅，最后只加一次静态总增益；章节卡轻"唰／咔嗒"，花字轻"Pop"，点击轻"叮"。**BGM 用代码原创配乐（20261111 起的 `music.py` 引擎，按镜头重编排），比人声低约 23 dB（2026-11-11 你嫌大），没有口播的成果段抬约 8 dB**；BGM 电平最初从比人声低约 18–20 dB 起步（木子 10 条实测整片 −14.6～−22.8 LUFS，前五条 −14.6～−16.8；BGM 单独电平无法分离，用说话停顿处估得比人声低 16–26 dB，是估计值，不是实测），再凭耳朵微调。

- **音效来源**：Openverse 上的 CC0（`license=cc0`，免署名可商用），每期把标题、作者、链接记进 `edit/sfx/openverse/来源.json`。**新音效先发你试听确认**再进成片。
- **转场／运动音效跟着画面动作走（2026-11-23）**：只在画面真的在动的地方放（开场、换场、窗口滑入、镜头拉远、东西飞过去），按动作快慢选长短，**声音最响的那一下对准动作最快的那一刻**；准备 2–3 种轮换，相邻不连用。不要用低频重、拖 1 秒左右的"嗖"（混在背景里听成一阵阵"嗡嗡"，压迫感强）。
- **试听排查**：你说某个声音不对时，从成片混音里原样导出分轨（背景＝配乐＋音效、只有配乐、只有人声，成片同增益，可另给放大版），一层层排除；不要把单层拉到满音量发你，音量一变听起来就像另一个版本。

## 剪气口与停顿（2026-11-24，整合「手动加入规则---待处理/气口等处理方式」并按全片 v1 的问题修正）

- **留白**：开口、收音按实测有声起止算，不按转写时间；开口前留约 0.15 秒、说完后留约 0.2 秒。≤0.35 秒的自然停顿保留；>0.35 秒：句内 0.4、逗号 0.35–0.45、句号 0.55、换段 0.7；剪掉口癖后的句内拼接处 0.04。停顿按成片时间（变速之后）算。片段之间一律硬切。
- **切点**：只能落在实测静音里，或两个字之间能量最低的地方；**不能直接用转写的字时间当切点**（字时间偏早，会把最后一个字切掉——11-23 全片 v1"一句话没说完就截断"就是这个原因，不是收音问题）。句尾：0.28 秒内收声就延到收声；后面紧接着还在说（被删的话）就切在字缝里。吸气、咳嗽不因此保留。
- **重复与重说**：同一段录了几遍只留一遍（条件相同时用后录的、能整段用的）；说一半重来的半截删掉。整段转写会把重说、口癖"吞掉"，所以要**两遍转写**：按 >0.3 秒停顿切块、不带提示词再转写一遍复核；剪完每行人声单独回听转写，和字幕逐字比，多出来的再剪。
- **剪什么、不剪什么**：只剪纯水词（那么、然后、因为、比如说、对吧、对啊、好的、好吧、嗯、呃、啊）、紧挨着的重复（"睡不着睡不着"）、≥4 字的多余片段；"这个／一个／的／就"这类虚词不剪（剪了一顿一顿），保留并补进字幕；拿不准的保留原声。
- **跨 take 拼接**：整段能用同一遍就不拼；要拼只在实测有静音的逗号、句号处拼，姿势位置差异明显时不拼，每处拼接写进交付说明。所有版本都有瑕疵时放瑕疵最轻的一遍。
- **该留的别删**：精简重复观点时，不要删掉体现身份和真实经验的具体细节（例：外贸负责的国家名）；对着软件说的话（听写给 Codex 的指令）原声保留，不静音。

## 录音与后期（2026-11-10 麦克风对比后定）

- **设备**：DJI Mic 发射端夹在领口／胸口，离下巴约 15–20 cm，略偏、不正对嘴；发射端增益用 **+6**。对比结论：领口原始电平很低（增益 0 约 −35 LUFS、−6 约 −40 LUFS，后期要补 +23～+28 dB），+6 约 −28 LUFS 只补 +15 dB，底噪最干净、低频爆音最少。录制时不要把增益往下调。
- **OBS 不加音频滤镜、不固化**：保持原始输入，全部后期处理，以防万一。
- **人声取录屏轨（2026-11-23）**：干净轨里机位轨 `*_cam.mkv` 的人声有毛刺，录屏轨 `*_screen.mkv` 是同一路麦克风、没有毛刺。人声一律从录屏轨取；录屏轨比机位轨早约 0.10–0.12 秒，每个 take 用互相关测一次，切点照机位时间写、取声时减去偏移。
- **后期**：每一期人声先过 `audio/voice_master.py`，再混 BGM。
  - 命令：`python voice_master.py 输入.mp4 输出.wav`（默认取第 1 轨、目标 −14.5 LUFS、真峰值 −2 dBTP）。
  - 链路：单声道 → 静态校到 −21 LUFS（让压缩器吃同一电平）→ 高通 80 Hz、330 Hz −3 dB、3 kHz +2 dB、6 kHz 以上 +2 dB → 轻压缩 2.5:1（启动 15 ms、释放 150 ms）→ 一次静态增益到目标 → 慢释放限幅（5 ms／120 ms）→ 双单声道 48 kHz。
  - 不降噪、不用 loudnorm。
- **处理量参考**：同一条链路下，领口麦原始偏暗（4–6 kHz 比对嘴录的低 10 dB 以上），所以高频这档是补偿；限幅最多削 3–4.6 dB，超过就说明录得偏冲或爆音多，先查录音。
- **领口夹麦不加防风罩**：加了会更闷，不用再测。
