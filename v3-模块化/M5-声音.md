# M5 声音

- **人声**：高通 → EQ → 压缩 → 一次静态增益；**不用动态响度（loudnorm）**，否则忽大忽小和毛刺。**混音里不对人声限幅**（音乐音效撞击时人声被压是毛刺的来源）；人声单独处理时，末尾只允许一道慢释放限幅削尖峰，削幅 ≤ 约 4 dB，超了就降人声目标响度，不硬压。防风海绵麦偏闷：EQ 削 130–520 Hz、轻提 1.5–2.8 kHz，不加混响；录音停顿处是数字静音，不需降噪。
- **整体匀声（2026-11-12）**：录着录着麦克风位置、坐姿会变，不同时段电平能差 5–10 dB。剪辑时按每一段的说话电平（50 ms 窗 RMS 的 75 分位）对齐到全片中位数，增益限制 −4～+10 dB，相邻几段取中位数平滑，≥1.2 dB 才调；出片后分段（2 秒窗）测一遍，说话段应落在约 3 dB 范围内，有突然变小的段落要回头查。
- **语速**：按段整条拉伸（约 1.10–1.34×，由每段实测字数／秒定），不用全局固定倍速，不对小片段单独拉伸；去开头口癖（然后／那么／呃／额）和重复句，通读保留的逐字稿再定稿。
- **响度**：整片约 −14 LUFS，真峰值 ≤ −2 dBFS；展映段人声静音，原声与口播同级或略高。**人声单独的标准 −14.5 LUFS（双声道，双单声道复制），真峰值 ≤ −2 dBTP（脚本留 0.3 dB 余量）**；先把人声定到这个值再加 BGM，不再用耳朵凭感觉。
- **音乐音效**：BGM 不盖人声，高通 160 Hz、低通 9 kHz，ducking 释放要慢；音乐、音效各自限幅，最后只加一次静态总增益；章节卡轻"唰／咔嗒"，花字轻"Pop"，点击轻"叮"。**BGM 电平从比人声低约 18–20 dB 起步**（木子 10 条实测整片 −14.6～−22.8 LUFS，前五条 −14.6～−16.8；BGM 单独电平无法分离，用说话停顿处估得比人声低 16–26 dB，是估计值，不是实测），再凭耳朵微调。

## 录音与后期（2026-11-10 麦克风对比后定）

- **设备**：DJI Mic 发射端夹在领口／胸口，离下巴约 15–20 cm，略偏、不正对嘴；发射端增益用 **+6**。对比结论：领口原始电平很低（增益 0 约 −35 LUFS、−6 约 −40 LUFS，后期要补 +23～+28 dB），+6 约 −28 LUFS 只补 +15 dB，底噪最干净、低频爆音最少。录制时不要把增益往下调。
- **OBS 不加音频滤镜、不固化**：保持原始输入，全部后期处理，以防万一。
- **后期**：每一期人声先过 `audio/voice_master.py`，再混 BGM。
  - 命令：`python voice_master.py 输入.mp4 输出.wav`（默认取第 1 轨、目标 −14.5 LUFS、真峰值 −2 dBTP）。
  - 链路：单声道 → 静态校到 −21 LUFS（让压缩器吃同一电平）→ 高通 80 Hz、330 Hz −3 dB、3 kHz +2 dB、6 kHz 以上 +2 dB → 轻压缩 2.5:1（启动 15 ms、释放 150 ms）→ 一次静态增益到目标 → 慢释放限幅（5 ms／120 ms）→ 双单声道 48 kHz。
  - 不降噪、不用 loudnorm。
- **处理量参考**：同一条链路下，领口麦原始偏暗（4–6 kHz 比对嘴录的低 10 dB 以上），所以高频这档是补偿；限幅最多削 3–4.6 dB，超过就说明录得偏冲或爆音多，先查录音。
- **领口夹麦不加防风罩**：加了会更闷，不用再测。
