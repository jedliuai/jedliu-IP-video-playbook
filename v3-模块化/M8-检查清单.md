# M8 出片前检查清单

**内容（[M1](M1-选题与定位.md)／[M2](M2-脚本.md)）**
- [ ] 第一句 ≤20 字，含结果或利益词；5 秒内出现成果画面
- [ ] 本期交付一个明确结果；章节为"问题第一"
- [ ] 每个数字都有实测记录；没有就删
- [ ] 有一段 ≤30 秒的"翻车与边界"，没有成串罗列限制
- [ ] 无"震惊／炸裂／一键三连"，无情绪升华收尾

**画面（[M3](M3-拍摄与录屏.md)／[M4](M4-剪辑与包装.md)）**
- [ ] 小窗不遮挡操作区；多窗口切换有左上角标签
- [ ] 章节卡骨架齐全（编号＋短标题＋插画＋`N / M`），停留 1–1.8 秒且口播暂停，外观是自己的
- [ ] 录屏字幕有底板；字幕每行 ≤18 字、无错字、无断行错误
- [ ] 有 10–20 秒成果展映
- [ ] 转场、B-roll、音效、音乐齐全，无吉祥物、无多余"标志性"小元素

**声音（[M5](M5-声音.md)）**
- [ ] 全片无毛刺、无忽大忽小；整片约 −14 LUFS，真峰值 ≤ −2 dBFS
- [ ] 口癖与重复句已清；BGM 不盖人声

**合规与版本（[M6](M6-平台版本与合规.md)）**
- [ ] 画面中无真实客户名、邮箱、价格、订单号、密钥、含隐私的路径
- [ ] AI 语音／形象／素材已按平台要求标注
- [ ] B 版：无二维码、联系方式、站外引流、营销话术
- [ ] 结尾：复盘一句→价值句→至多一个有理由的动作；最后一句说完即停，无片尾卡、无三连、无告别腔
- [ ] 只出两版：A 版和 B 版（抖音、小红书共用同一个 B 版文件）
- [ ] B 版：无服务提示、无网址／联系方式、无私信／点赞收藏引导；若有"评论区拿资料"，资料真实存在
- [ ] B 版：全片（口播、字幕、画面、标题、简介、标签）无违禁词（如"绿盾"，统一说"加密软件"）
- [ ] 开头没有身份句／自我介绍
- [ ] 没有无合作却做"官方活动／奖品"式结尾

**发布（[M7](M7-标题发布与运营.md)）**
- [ ] 标题、简介、标签、封面、置顶评论已按平台分别写好
- [ ] 封面承诺在视频里兑现
