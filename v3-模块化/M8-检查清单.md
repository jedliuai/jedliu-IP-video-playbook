# M8 出片前检查（只列容易漏的）

- [ ] 只出两版（A、B）；B 版抖音／小红书共用
- [ ] B 版：全片（口播、字幕、画面、标题、简介、标签）无违禁词；无服务提示、联系方式、私信／点赞收藏引导；口播不念网址
- [ ] 画面里没有真实客户名、邮箱、订单号、价格、密钥、含隐私的路径（M3 列的除外）
- [ ] 每个数字都有实测记录，没有就删
- [ ] 开头没有身份句；第一句 ≤20 字，5 秒内有成果画面
- [ ] 结尾：复盘一句→价值句→至多一个动作，说完即停，无片尾卡
- [ ] 有 15–40 秒成品展映；章节卡骨架齐全且口播暂停
- [ ] 全片无毛刺、无忽大忽小（分段测电平，说话段约 3 dB 内）；字幕无错字、无断行错误
- [ ] 开头没有卡壳、重复起句；同一个词没有在一章里反复出现
- [ ] 画面里**没有露出口播稿／提词稿**（含 OBS 预览的递归画面）；所有录屏镜头逐个看过静帧
- [ ] 转场／卡片停留够久（章节卡完整展示 ≥1.4 秒）；文字没有溢出边框
- [ ] 具体软件／品牌用的是真实 logo，不是通用图标
- [ ] AI 语音／素材已按平台要求标注
- [ ] 封面承诺在视频里兑现
