# 个人 IP 视频规则（模块化）

唯一有效的规则版本。每条规则只写在它所在的那一个模块里，不重复。

## 工作约定
1. 制作某个视频时你提的修改建议，如果是**通用型**的，我先征得你同意，再写进本规则。
2. 改脚本：直接给完整的新版脚本，不写修改说明（[M2 §0.2](M2-脚本.md)）。
3. 写脚本前先读项目链接、采访你、保留原话、先出底稿、只整理不脑补（[M2 §0.1](M2-脚本.md)）。
