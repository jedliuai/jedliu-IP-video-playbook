# 个人 IP 视频规则 v3（模块化）

> 这是唯一有效的规则版本，由早期单文件规则 + 对标账号「木子不写代码」拆解后的取舍整合而成。旧版本已删除，可在 git 历史中找回。
> 取舍总原则：**学他的"叙事结构 + 视觉包装 + 效率型口播"，不学他的"人设符号 + 题材路线"。**

## 工作约定（沿用你定的两条）

1. 制作某个视频时你提的修改建议，如果是**通用型**的，我先征得你同意，再写进本规则。
2. 你提出修改脚本时，直接给**完整的新版脚本**：不标注改动、不写修改说明，回复里也不啰嗦。详见 [M2 §0.2](M2-脚本.md)。
3. 写脚本之前先读项目链接，再采访你、保留你的原话、先出底稿等你确认、成文只整理不脑补。详见 [M2 §0.1](M2-脚本.md)。

## 已定事项（2026-11-08）

1. **时长**：不预设上限，按实际录制内容和节奏定。
2. **抖音不带任何服务提示**（太危险）。服务提示只在 A 版平台出现。
3. **抖音结尾**：参照木子的真实做法——"戛然而止"：复盘一句 → 价值句（本期自己的结论）→ 至多一个有理由的动作，说完即停，无片尾卡、无告别语。见 [M6](M6-平台版本与合规.md)（依据 `分析/01` 六点五、`分析/05`）。
4. **不做身份句**：开头不说"白天我做外贸"之类的自我介绍，直接给结果。
5. **视频号沿用 A 版**。
6. **不用卡通吉祥物**（片头、转场、片尾都不用）。
7. **不设固定签名句／口号**：价值句用每期自己的真实结论。
8. **抖音可开"评论区拿资料"，小红书先试水**：资料要真有，视频里不出现网址和联系方式；小红书出现限流或违规提醒就停用。
9. **小红书的"关注"**：把"对我的作品感兴趣，关注我就行"以画面文字叠在最后一句话上，不另做片尾。
10. **违禁词**："绿盾"在 B 版一律说"加密软件"，A 版录制时就这样说。见 [M6 违禁词](M6-平台版本与合规.md)。
11. **只出两版**：A 版（B站、YouTube、视频号）和 B 版（抖音、小红书共用同一个文件，按更严标准做）。见 [M6 硬规则](M6-平台版本与合规.md)。以后有变化再改。
