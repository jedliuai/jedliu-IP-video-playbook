## 工作约定（沿用你定的两条）

1. 制作某个视频时你提的修改建议，如果是**通用型**的，我先征得你同意，再写进本规则。
2. 每次按你的要求更新脚本，直接给**完整的新版脚本**，不在脚本里标注与上一版的差异。

## 已定事项（2026-11-08）

1. **时长**：不预设上限，按实际录制内容和节奏定。
2. **抖音不带任何服务提示**（太危险）。服务提示只在 A 版平台出现。
3. **抖音结尾**：参照木子的真实做法——"戛然而止"：复盘一句 → 价值句／签名句 → 至多一个有理由的动作，说完即停，无片尾卡、无告别语。不放站外信息、不用评论区领资料。见 [M6](M6-平台版本与合规.md)（依据 `分析/01` 六点五、`分析/05`）。
4. **不做身份句**：开头不说"白天我做外贸"之类的自我介绍，直接给结果。
5. **视频号沿用 A 版**。

## 仍待定

2. **签名句**：从 M6 候选里固定 1–2 句（或用自己的）。
3. **抖音是否开"评论区领资料"**：M6 暂不开。
4. **小红书的"关注"**：暂按"画面文字叠在最后一句上"；你之前的小红书版有短片尾字幕，是否沿用？
